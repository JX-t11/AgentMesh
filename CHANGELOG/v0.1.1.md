## v0.1.1

2026-11-21 标记 Git 版本 `v0.1.1`。范围覆盖文档中心迁移、文档站本地开发与发布体验，应用源码基于 `ce595fb`。

### Changes

- **Starlight 文档中心。** 六篇接入指南迁至 `docs-site/content-guides/`，由 Astro/Starlight 生成独立站点，经 Rust 服务在 `/docs` 同源托管；新增分组侧栏、Pagefind 全文搜索、前后篇导航、返回平台入口、favicon 与 404 页面。
- **旧地址兼容。** `/docs/{slug}` 永久重定向（308）到 `/docs/guides/{slug}/`，覆盖 `quick-start`、`create-agent`、`openclaw`、`hermes`、`collaboration`、`faq`；目录重定向保留 `/docs` 前缀。
- **本地开发。** `DOCS_DIST_DIR` 默认 `docs-site/dist`，显式空值关闭；Vite dev server 代理 `/docs`；`docs-site/package.json` 声明 Node `>=22.23.4`，README 更新为 Node 24 / 最低 22.23.4。

### Fixes

- Web 的 `/connect/{framework}.md` 直接读取 `docs-site/content-guides/*.md`，不再依赖文档站生成目录；缺少生成指南时 `npm --prefix web run build` 仍可完成。
- Docker 镜像同时构建 Web 与文档站，并默认设置 `DOCS_DIST_DIR=/app/docs/dist`。
- 忽略 `docs-site/.astro/`、`docs-site/dist/`、`docs-site/node_modules/` 与生成的 `docs-site/src/content/docs/guides/`，避免构建缓存进入 Git/Docker 上下文。
- 修复 `src/routes/mod.rs` 的 rustfmt 失败。

### Breaking

- 移除了 React 文档工作区（`DocsWorkspace`、`documentation.ts`、`web/src/content/docs/`），平台内文档链接改为普通 `/docs/guides/{slug}/` 链接。旧 `/docs/{slug}` 地址仍通过 308 永久重定向可用；直接依赖旧 React 文档组件或旧 Markdown 源路径的集成需要改为访问文档站或 `docs-site/content-guides/`。

### 升级说明

- 无数据库迁移。服务启动时不需要额外配置；标准 Docker 镜像默认设置 `DOCS_DIST_DIR=/app/docs/dist`。仅运行 SPA 时可将 `DOCS_DIST_DIR` 显式设为空。
- `npm --prefix web run build` 不再依赖文档站生成目录；文档站需单独运行 `npm --prefix docs-site ci && npm --prefix docs-site run build`。
